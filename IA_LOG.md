# 🤖 Registro de uso de Inteligencia Artificial

Durante el desarrollo de Dante se utilizó Inteligencia Artificial como herramienta de apoyo.

## Interacción 1 - Programación de la mascota

### Prompt utilizado
Necesito hacer una mascota virtual en Python con Pygame que tenga barras de energía, ánimo y bugs, y botones para interactuar con ella.

### Reglas de Oro

- **Claridad:** se explicó qué programa se quería realizar y qué funciones debía tener.
- **Contexto:** se indicó que era un trabajo práctico escolar realizado en Python y Pygame.
- **Fundamentación:** se explicó para qué se necesitaban las barras y los botones.
- **Solicitud de ejemplos:** se solicitaron ejemplos de código para implementar las funciones.

### Verificación
Se probó el código en Visual Studio Code y se comprobó que los botones y las barras funcionaran correctamente.

---

## Interacción 2 - Corrección de errores

### Prompt utilizado
Tengo un problema porque las variables de energía, ánimo y bugs pueden quedar fuera del rango de 0 a 100, Como puedo solucionarlo?

### Reglas de Oro

- **Claridad:** se explicó específicamente cuál era el problema.
- **Contexto:** se indicó que el código estaba realizado en Python con Pygame.
- **Fundamentación:** se explicó que los valores debían mantenerse entre 0 y 100.
- **Solicitud de ejemplos:** se pidió código para solucionar el problema.

### Verificación
Se modificó el código y se probaron los botones varias veces para comprobar que los valores no fueran menores que 0 ni mayores que 100.

## Interacción 3 - Estados de Dante

### Prompt utilizado
Quiero que Dante cambie de imagen según su estado, por ejemplo cuando está cansado, tiene muchos bugs o está programando.

### Reglas de Oro

- **Claridad:** se explicó que Dante debía cambiar de imagen según sus valores y acciones.
- **Contexto:** se indicaron las imágenes disponibles y el uso de Pygame.
- **Fundamentación:** se explicó qué situación debía representar cada imagen.
- **Solicitud de ejemplos:** se solicitaron ejemplos para implementar el cambio de imágenes.

### Verificación
Se ejecutó el programa y se probaron las diferentes situaciones para comprobar que Dante cambiara correctamente de imagen.
