# 🐬 Dante - Mascota Virtual de Informática

## 🐬 ¿Qué es Dante?

Dante es una mascota virtual hecha en Python con Pygame.

Tiene tres barras:

- ⚡ Energía
- 😄 Ánimo
- 🐞 Bugs

El jugador puede alimentar, jugar, programar y reparar sus bugs para mantenerlo en buen estado.

Dante también cambia de imagen según su estado.

## 🎮 Controles

- **Alimentar:** aumenta energía y ánimo.
- **Programar:** aumenta los bugs.
- **Jugar:** aumenta el ánimo.
- **Reparar Bugs:** reduce los bugs.

Los valores van de 0 a 100.

## 🛠️ Tecnologías

- Python
- Pygame
- Visual Studio Code
